# Security policy

Product Design Director is a Markdown instruction file and documentation repository; it does not include executable runtime code. Reports are still useful when instructions or examples could cause disclosure of private data, unsafe handling of references, misleading security guidance, or unauthorized asset use.

## Reporting

If GitHub private vulnerability reporting is available for this repository, use the repository's **Security** tab. If no private channel is available, open a minimal issue that requests maintainer contact without including exploit details, credentials, private product data, or personal data.

Include the affected file and section, impact, reproduction conditions, and the smallest safe remediation. Do not attach secrets or confidential Figma files.

Security support currently applies to the default branch. Historical instruction versions may not receive fixes.
