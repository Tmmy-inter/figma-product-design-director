## LinkedIn long post

AI-assisted product UI has a design-judgment problem before it has a styling problem.

When the brief is thin, the interface can collapse into familiar defaults: equal-weight cards, weak hierarchy, missing interaction states, decorative visuals, and a desktop composition simply compressed for mobile.

Product Design Director is an open-source Custom Skill that gives the Figma agent a structured sequence for that judgment work:

1. Start from product purpose, users, primary task, content, brand evidence, and authoritative references.
2. Set hierarchy and region ownership before decoration.
3. Choose the layout model that fits the task instead of defaulting to cards.
4. Define coherent visual-system and component-state decisions.
5. Adapt by priority across widths.
6. Critique the result using observed condition, user impact, and the smallest reasonable revision.

It also covers interaction feedback, purposeful motion, reduced motion, and accessibility review guidance. Those instructions do not guarantee a better or accessible design; output remains dependent on context and agent execution, and implementation validation still matters.
