## Short description

An open-source Custom Skill that guides product context, visual systems, hierarchy, layout, component states, responsive behavior, interaction, motion, accessibility review, and critique in Figma.

## Long description

Product Design Director packages a structured product-design workflow into one standalone Markdown skill for the Figma agent and Figma Make.

It begins with product purpose, users, primary tasks, brand evidence, content, and supplied references. It then directs the agent to define hierarchy before decoration, choose a layout model that fits the task, use coherent visual-system decisions, cover relevant component states, adapt by priority at narrow widths, and critique the result.

The skill is intended to reduce common generic-interface patterns such as equal-weight card grids, weak hierarchy, missing states, decorative visuals without a product role, and mobile frames that simply compress a desktop composition.

This is design direction, not deterministic output. Results depend on the context, references, content, model behavior, and agent execution. Accessibility guidance still requires implementation-level validation and human review.

## How to use

1. Add the skill from its verified Community page or upload the repository's `SKILL.md`.
2. Invoke `/figma-product-design-director` in a supported Figma chat.
3. Supply the product goal, users, main task, real content, constraints, target frames, and authoritative references.
4. Review the proposed hierarchy, states, responsive decisions, and critique.
5. Validate product decisions and implementation behavior with humans and the relevant testing methods.
