# Product Design Director launch pack

> **HUMAN-REVIEWED SOURCE MATERIAL.** Nothing in this directory records an external publication. Resolve every required variable, evidence gate, account authorization, and channel rule immediately before use.

## Canonical variables

Use only these variable names across launch source files:

| Variable | Meaning |
| --- | --- |
| `{{FIGMA_COMMUNITY_URL}}` | Verified public Community listing |
| `{{GITHUB_REPOSITORY_URL}}` | Verified public source repository |
| `{{SUPPORT_URL}}` | Public feedback or support destination |
| `{{CASE_STUDY_URL}}` | Real, reviewed same-brief case study |
| `{{DEMO_VIDEO_URL}}` | Reviewed public demo video |
| `{{RELEASE_URL}}` | Published GitHub Release |

Missing inputs and acceptance evidence are centralized in [`human-input-required.md`](human-input-required.md).

## Execution order

1. Approve the product name, technical skill name, affiliation statement, and claims ledger.
2. Run and document a reproducible Figma import-and-invocation test.
3. Capture a real same-brief comparison using the fixed-variable protocol.
4. Review every SVG and exported image in `preview.html` at desktop and narrow widths.
5. Resolve Community, repository, support, case-study, demo, and Release URLs.
6. Adapt one channel draft to the current channel rules; do not cross-post unchanged copy.
7. Obtain explicit authorization for the exact account and publication action.
8. Record the final URL in `link-matrix.csv` and real observations in `metrics-template.csv` after publication.

Stop if a link, result, channel rule, account, image, or capability claim cannot be verified.
