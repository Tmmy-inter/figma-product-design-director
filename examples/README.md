# Copyable examples

These examples are task briefs for a successfully uploaded `/figma-product-design-director` Custom Skill. They describe what the skill should examine; they do not claim that a specific output has been produced or validated.

| Example | Use it when |
| --- | --- |
| [Dashboard redesign](01-dashboard-redesign.md) | An existing operational surface has weak hierarchy or a template-like layout. |
| [Product-flow audit](02-product-flow-audit.md) | A multi-step flow needs a structured critique of actions, states, and continuity. |
| [Responsive adaptation](03-responsive-adaptation.md) | A wide interface must become a priority-led narrow/mobile experience. |
| [Visual-system direction](04-visual-system-direction.md) | A real product needs coherent visual and component rules grounded in brand evidence. |
| [Design critique](05-design-critique.md) | Existing frames need an evidence-based issue and revision pass. |

Use [`case-study-template.md`](case-study-template.md) only after running a real, fixed-variable comparison. Do not present the blank template as a case study.

## Before invoking

Provide the product goal, primary users, main task, real content, constraints, existing system, authoritative references, required states, and target frame sizes. Remove secrets and private product data before sharing material.
